# entities-multiplayer-fabric-rpg

Pins the multiplayer fabric's role-playing layer: a planning player bot, its planner library and a local language-model runtime.

## What it is for

The bot plays an online role-playing game through the game's API with plans from the taskweft hierarchical task network planner. `OBJECTIVE.md` states the conditions the bot is built to meet, and `.gitmodules` names the repositories it pins.

## Get it

```sh
git clone --recurse-submodules https://github.com/V-Sekai-fire/entities-multiplayer-fabric-rpg.git
```
